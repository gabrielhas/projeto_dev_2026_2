Visao Geral do Projeto

O Sistema de Solicitacao de Jogos e uma aplicacao web fullstack desenvolvida para o evento MuPy 2026. Permite que usuarios comuns enviem solicitacoes de jogos para plataformas especificas (PS4, PS5, Xbox Series e Nintendo), enquanto administradores gerenciam essas solicitacoes por um painel protegido.

1.1 Arquitetura do Sistema

O projeto segue uma arquitetura monorepo com separacao clara entre frontend e backend, comunicando-se via API REST sobre HTTP.
